# 03 · Quota 和调度

> [English](03-quota.md) | 中文

**Blocked by**: 02

## 做什么
- 先实现 Quota 的 5 个维度：同时存在的 Sandbox 数、vCPU 总数、内存总量、单个 Sandbox 最长存活时间、创建速率（Volume 总容量在 15 里加）
- Host 注册时上报容量；调度用 first-fit；内存不超卖，CPU 超卖比例可以按 Host 配置（默认 1.0）
- 请求了 GPU 就明确返回"不支持"

## 验收
- [ ] 每个维度超额都直接拒绝，错误信息说明是哪一项超了
- [ ] 两个创建请求同时到达时不会一起超额（并发测试）
- [ ] Host 资源不够时返回"容量不足"，和"Quota 超额"是两种不同的错误
